Карта уроку

Функція — це правило: одне x → одне y

Два імені для двох змінних

Незалежна змінна — x, її ще звуть аргументом. Її ми обираємо самі.

Залежна змінна — y, це значення функції. Її рахує формула.

Як це виглядає

y = 3x − 5

Підставив x = 2 — отримав єдине y = 1. Двох різних відповідей бути не може.

У чат — номери

№ 45 (ст. 8) · усно

Які записи задають функцію? Назвіть аргумент

1) m = 2p − 9

Так. Аргумент p, залежна m.

2) 4x − 9 = 9 − 4x

Ні — це рівняння, тут одна змінна.

3) y = 2xx − 3

Так. Аргумент x, залежна y.

4) 36 : 9 − 4 = 0

Ні — тут немає змінних, це просто числова рівність.

5) c = n2 − n3

Так. Аргумент n, залежна c.

6) 2x − 9 > 3

Ні — це нерівність.

Ознака функції: дві різні букви й знак «=», причому одна буква виражена через другу.

У зошит

№ 47 (ст. 8) · функцію задано формулою y = 3 − 2x

В обидва боки: за x знайти y і навпаки

1) Значення функції

x = −4:  y = 3 − 2 · (−4) = 3 + 8 = 11

x = 1,5:  y = 3 − 2 · 1,5 = 3 − 3 = 0

2) Значення аргументу

y = −7:  3 − 2x = −7 → −2x = −10 → x = 5

y = 5:  3 − 2x = 5 → −2x = 2 → x = −1

Різниця в один крок: у пункті 1) ми підставляємо, у пункті 2) — розвʼязуємо рівняння. Плутати їх — найчастіша помилка в цій темі.

Зупинка 2

Область визначення — це всі x, які взагалі можна підставити

Коли можна все

Якщо у виразі немає ділення на змінну — підставляй будь-яке число.

y = 5x − 1

Область визначення: усі числа.

Коли є заборона

Змінна у знаменнику — знаменник не має права дорівнювати нулю.

y = 4x − 5  →  x − 5 ≠ 0

Отже x ≠ 5.

Порядок дій завжди однаковий: прирівняй знаменник до нуля → розвʼяжи → постав «≠».

Зупинка 3

Нуль функції — це x, при якому y = 0

Що робити

1) Замінити y на 0.

2) Розвʼязати рівняння відносно x.

3) Знайдений x — і є нуль функції.

Приклад

y = 5x + 10

5x + 10 = 0

5x = −10,   x = −2

У відповідь пишемо значення x, а не нуль. «Нуль функції дорівнює −2» — правильно; «нуль функції дорівнює 0» — ні.

На графіку нуль функції — це точка, де лінія перетинає вісь x.

Зупинка 4

Лінійна функція: y = kx + b

Як упізнати

x стоїть у першому степені, він не в знаменнику й не під коренем. k і b — просто числа.

y = 2x − 3  k = 2, b = −3

Графік — завжди пряма

А пряму задають дві точки. Тому для побудови досить таблиці з двох рядків.

y = x + 3 → (0; 3) і (−3; 0)

Найзручніші дві точки — де пряма перетинає осі: підстав x = 0, а потім y = 0. Друга з них — це якраз нуль функції, який ми щойно вчилися шукати.

У чат — номери лінійних

№ 46 (ст. 8) · усно

Чи є функція лінійною?

1) y = 2x2

Ні — квадрат

2) y = 2x

Так k = 2, b = 0

3) y = 2

Так k = 0, b = 2

4) y = 12x − 3

Ні — x у знаменнику

5) y = 2x − 3

Так k = 2, b = −3

6) y = 2x2 − 3

Ні — квадрат

Пункт 3) багатьох збиває: y = 2 теж лінійна, просто k = 0. Її графік — горизонтальна пряма.

У зошит — креслимо

№ 53 (ст. 8)

Побудуйте графік лінійної функції

Спершу — по дві точки на кожну пряму. Осі підпиши, одиничний відрізок — 1 клітинка.

ФункціяПерша точка (x = 0)Друга точка
1) y = x + 3(0; 3)(−3; 0)
2) y = 7 − 0,5x(0; 7)(2; 6)
3) y = −4x(0; 0)(1; −4)
4) y = 2(0; 2)(3; 2)

Другу точку бери таку, щоб вийшли цілі числа. Для 2) зручне x = 2, а не x = 1.

№ 53 · перевіряємо себе

Ось як мають лягти всі чотири прямі

Одиничний відрізок — одна клітинка
y = x + 3 y = 7 − 0,5x y = −4x y = 2

Що видно з малюнка

Синя й жовта прямі піднімаються або спадають полого, червона — майже стрімка. Що більший k за модулем, то крутіша пряма.

Зелена y = 2 — горизонтальна: хоч який x, значення завжди 2.

Червона проходить через початок координат, бо в y = −4x немає вільного члена: b = 0.

У зошит — памʼятка

Памʼятка

Два числа, які розповідають про пряму все

k > 0

Функція зростає: пряма йде вгору зліва направо.

k < 0

Функція спадає: пряма йде вниз.

k = 0

Пряма горизонтальна: y = b.

b — це y у точці перетину з віссю y. Тобто пряма перетинає вертикальну вісь саме на висоті b.

Перевір на малюнку з попереднього слайда: у y = x + 3 маємо b = 3 — і пряма справді проходить через точку (0; 3).

№ 57 (ст. 9) · без побудови

Знайдіть точки перетину графіка з осями координат

1) y = 0,5x − 4

з віссю y: x = 0 → y = −4   (0; −4)

з віссю x: y = 0 → 0,5x = 4   (8; 0)

2) y = 16 − x2

з віссю y: x = 0 → y = 16   (0; 16)

з віссю x: 16 − x2 = 0 → x2 = 16

(−4; 0) і (4; 0)

У пункті 2) функція не лінійна, тому нулів може бути два. Не загуби другий корінь: із x2 = 16 випливає x = 4 і x = −4.

Функція

Правило: кожному x відповідає рівно одне y. x — аргумент, y — значення функції.

Область визначення

Усі числа, крім тих, що обертають знаменник на нуль.

Нулі функції

Підставили y = 0 і розвʼязали рівняння. Це точки перетину з віссю x.

Графік

У y = kx + b графік — пряма; будуємо за двома точками.
