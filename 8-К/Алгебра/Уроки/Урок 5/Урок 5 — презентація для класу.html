§ 1 · ст. 12

Чи є ділення на вираз зі змінною?

Цілі вирази — немає

5m2p;   (m − n)(m2 + n7);   k9 − p + l4

Дробові вирази — є

5m − 3p;   x + 2y − 9;   1(x − y)(x2 + 7)

Раціональні вирази = цілі + дробові. Вони містять лише додавання, віднімання, множення, ділення й піднесення до степеня.

k9 − p + l4 — цілий: ділимо на число 4, а не на змінну. Змінна в чисельнику нічого не псує.

Знайдіть значення виразу

1) 3a + 9a2, якщо a = 1; −2; −3

a = 1:  3 · 1 + 912 = 121 = 12

a = −2:  3 · (−2) + 9(−2)2 = 34

a = −3:  3 · (−3) + 9(−3)2 = 09 = 0

2) x + 3x − xx − 2, якщо x = 4; −1

x = 4:  74 − 42 = 74 − 2 = −14

x = −1:  2−1 − −1−3 = −2 − 13 = −213

Відʼємне число підставляємо в дужках: (−2)2 = 4, а не −4.

§ 1 · ст. 13 · приклад 1

На нуль ділити не можна

Значення змінних, для яких вираз має зміст, називають допустимими значеннями змінних. Разом вони утворюють область допустимих значень (область визначення) виразу.

Для дробу PQ шукаємо, коли знаменник Q = 0, — ці значення виключаємо.

Знайдіть допустимі значення змінної у виразі:

1) m − 39

m — будь-яке число

2) 5p + 2

p ≠ −2

3) x + 7x(x − 9)

x ≠ 0; x ≠ 9

4) 7|y| − 3

y ≠ 3; y ≠ −3

Цілий вираз має зміст завжди. У 4): |y| = 3 має два розвʼязки — не губимо −3.

§ 1 · ст. 13–14 · приклад 2

Умова рівності дробу нулю

PQ = 0  тоді й тільки тоді, коли  P = 0,Q ≠ 0.

Для яких значень змінної дорівнює нулю значення дробу:

1) x − 3x + 1

x = 3

2) (a − 2)(a + 1)a + 5

a = 2; a = −1

3) b(b − 7)b − 7

лише b = 0

У 3) чисельник = 0 ще й при b = 7, але тоді й знаменник = 0 — дріб не має змісту. Перевіряй обидві умови.

Підсумок

Цілий чи дробовий

Є ділення на вираз зі змінною — дробовий. Разом — раціональні вирази.

Раціональний дріб

PQ, де P і Q — многочлени. Значення — підставляємо в дужках.

Допустимі значення

Знаменник = 0 → це значення виключаємо. Решта — допустимі.

Дріб = 0

Чисельник = 0 і знаменник ≠ 0.

Одна відповідь вголос: чи може дріб x − 5x − 5 дорівнювати нулю?

Ні. При x = 5 він не має змісту, а при інших x дорівнює 1.
