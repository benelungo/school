Головне питання

Чому не можна просто сказати «прочитай текст із фото»?

Бо людська мова багатозначна. Ми домовляємось про зміст на ходу, за здогадкою й контекстом. Машина здогадуватись не вміє.

Одне слово — різні речі

Замок — на дверях чи на горі?
Коса — дівоча, річкова чи для трави?

Одне речення — два змісти

«Я бачив хлопця з телескопом.»
Телескоп у мене чи в нього?

Пропущені кроки

«Прочитай текст із фото.»
З якого файлу? Якою мовою? Куди подіти результат?

Тому й придумали штучні мови: у них кожен запис має рівно один зміст. Слів мало, правила суворі — зате двох тлумачень не буває ніколи.

Спускаємось на найнижчий рівень

А що процесор розуміє насправді?

Тільки машинний код — числа, записані нулями й одиницями. Ніяких слів. Взагалі.

Наприклад, команда «поклади число 1 у комірку процесора» на процесорах Intel — це п'ять байтів:

10111000  00000001  00000000  00000000  00000000

Порівняйте з українською: алфавіт — 33 букви, синтаксис — правила побудови речень, семантика — значення слів. Різниця одна: за порушення синтаксису українська пробачає, а мова програмування — ні. Забув дужку — програма не запуститься.

Хто ж перекладає код у нулі й одиниці

Програма-перекладач називається транслятор. Їх два види.

Компілятор

Перекладає всю програму одразу й складає готовий файл. Далі його запускають без перекладача.

Як письмовий переклад книжки: довго, зате потім читаєш скільки хочеш.

Так працюють C, C++

Інтерпретатор

Перекладає й одразу виконує рядок за рядком, щоразу заново.

Як усний перекладач поруч: почав говорити — переклад уже йде.

Так працює Python

Саме тому Python зручний для навчання: написав рядок — одразу бачиш результат, чекати нічого не треба. Плата за це — програма працює повільніше за скомпільовану.

Головна причина, чому мета досяжна

Навчити комп'ютер відрізняти «а» від «о» на фотографії — це роки роботи сотень людей. За один навчальний рік це не пишеться. І не треба.

Чому це важливо саме для нас

Розпізнаний зі сторінки номер будинку «12» — це текст, а не число. Поки ми не скажемо Python перетворити його на число, він не зможе його додати. Лапки — перемикач між цими двома світами.

У зошитВідповіді — у чат, коли скажу

Що виведе кожна програма?

КодНа екрані буде
print(10 + 5)15
print("10 + 5")10 + 5
print("10" + "5")105  — тексти не додаються, а склеюються
print("Привіт", "9-А")Привіт 9-А  — кома ставить пробіл
print(3 * 4)12  — зірочка означає «помножити»

Найважливіший рядок тут — третій. Плюс для чисел — це додавання, а для текстів — склеювання. Один і той самий знак, дві різні дії. Python дивиться не на знак, а на те, що ним з'єднують.

У зошит: випиши правильний варіант

Знайди помилку в коді

Усі три програми мали вивести слово Привіт. Жодна не запуститься.

№ 1

print("Привіт)

Не закрита лапка. Треба: print("Привіт")

№ 2

Print("Привіт")

Велика літера P. Python розрізняє великі й малі: print і Print — різні слова

№ 3

print "Привіт"

Немає дужок. Треба: print("Привіт")

Такі помилки називають синтаксичними — порушено правила запису. Це найлегший вид помилок: Python сам покаже рядок і скаже, що не так. Значно гірші ті, коли програма працює, але робить не те. До них ми ще дійдемо.
