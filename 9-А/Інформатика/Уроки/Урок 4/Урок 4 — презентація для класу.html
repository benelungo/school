Колір RGB. Арифметика над зображенням

Три ліхтарики в одну точку

слухаємо поясненняозначення — у зошит

Уявіть три ліхтарики — червоний, зелений, синій — які світять в одну точку. Крутите яскравість кожного — і отримуєте будь-який колір. Червоний + зелений = жовтий, усі три на повну = білий.

Означення

Кольоровий піксель — це три числа (R, G, B): скільки червоного, зеленого й синього. Кожне — від 0 до 255.

Кольорове фото — це три таблиці, накладені одна на одну.

Який це колір?

випадковий номер — один колірвголос

Три числа — це яскравості червоного, зеленого й синього ліхтариків. Уявіть, що світить.

1) (255, 255, 0)
жовтий
2) (0, 255, 255)
блакитний
3) (255, 0, 255)
пурпуровий
4) (255, 140, 0)
помаранчевий

А якщо всі три таблиці однакові?

бажаючий — з поясненням

У кожному пікселі R = G = B: наприклад (90, 90, 90) або (200, 200, 200). Яке вийде фото?

Відповідь

Жоден ліхтарик не переважає — колір не зʼявляється. Виходить сіре фото: чим більше число, тим світліше. Саме таке ми розбирали минулого уроку.

Colab · кольорове фото — таблиця з трьома шарами

from PIL import Image
import numpy as np
import matplotlib.pyplot as plt

img = np.array(Image.open('foto.jpg'))   # без .convert('L')!
print(img.shape)        # (висота, ширина, 3)
print(img[140, 150])    # один піксель: [R G B]
plt.imshow(img); plt.show()
вивід для тестового зображення
(480, 640, 3)
[255 235 156]

Третє число в shape — це 3 шари. Піксель у сонці: червоного на повну, зеленого трохи менше, синього мало — ось і жовтий.

У чат: ваш img.shape і будь-який піксель img[r, c].

Кожен шар окремо: канали R, G, B

for k in range(3):                   # 0 — червоний, 1 — зелений, 2 — синій
    plt.imshow(img[:, :, k], cmap='gray', vmin=0, vmax=255)
    plt.show()

Кожен канал — звичайна сіра таблиця. Небо вгорі світле лише в каналі B, сонце — у R і G: де ліхтарик світить сильніше, там світліше.

Практика · ламаємо кольори

самостійно в Colabбажаючий — скриншот на екран
b = img.copy()
b[:, :, 2] = 0           # вимкнули синій ліхтарик
plt.imshow(b); plt.show()

s = img[:, :, [2, 1, 0]]  # поміняли R і B місцями
plt.imshow(s); plt.show()

.copy() обовʼязково: без нього ви зіпсуєте сам img, і наступні клітинки працюватимуть із фото без синього.

Фоторедактор — це арифметика

слухаємо поясненнятри формули — у зошит

Підняти всьому класу оцінку на бал — це додати 1 до кожної клітинки журналу. З фото так само: одна дія — над кожним з мільйонів чисел.

Що робимоНад кожним числомУ Python
Освітлитидодатиa + 50
Негатив255 мінус число255 - a
Контрастпомножитиa * 1.5

Тут a — сіра таблиця з минулого уроку: a = np.array(Image.open('foto.jpg').convert('L')).

Негатив одним рядком

a = np.array(Image.open('foto.jpg').convert('L'))
n = 255 - a
plt.imshow(n, cmap='gray', vmin=0, vmax=255)
plt.show()
print(a[140, 150], n[140, 150])
232 23

Білий 255 → 0, чорний 0 → 255. Сонце стало чорним, а пагорби — світлими.

Освітлюємо — і фото «перевертається»

випадковий номер — скільки буде?
x = np.array([250], dtype=np.uint8)
print(x + 20)       # скільки?
[14]

uint8 — 1 байт, 270 не влазить. Іде по колу, як годинник: 270 − 256 = 14.

l = np.clip(a.astype(int) + 100, 0, 255).astype(np.uint8)

Рахуємо в int, clip обрізає все понад 255, потім назад у uint8.

Практика · освітлення й контраст

самостійно в Colabбажаючий — скриншот на екран

Завдання

  1. Освітліть своє фото на 100 через clip — без плям.
  2. Зробіть контраст: np.clip(a * 1.5, 0, 255).astype(np.uint8).
  3. Встигли? Спробуйте * 0.5 — що сталося?

Множення розтягує різницю між темним і світлим — це й є контраст. × 0.5 навпаки стискає: фото темніше й «пласкіше».

Підсумок уроку

Три речення в зошит

  1. Кольорове фото — три таблиці R, G, B; img.shape = (висота, ширина, 3). Якщо R = G = B — фото сіре.
  2. Освітлення, негатив і контраст — це додавання, віднімання від 255 і множення над кожним числом.
  3. У uint8 числа йдуть по колу (250 + 20 = 14), тому рахуємо в int і обрізаємо clip.
