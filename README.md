# Уроки

Сайт із презентаціями уроків для учнів. Головна сторінка — `index.html`.

## Автопублікація

Зміни підхоплюються самі: зберегли файл — і за кілька секунд він уже на GitHub,
ще за хвилину оновився сайт.

```
python3 tools/autopublish.py --install     # увімкнути назавжди (стартує при вході)
python3 tools/autopublish.py --status      # перевірити, чи працює
python3 tools/autopublish.py --uninstall   # вимкнути
```

Що відбувається на кожну зміну:

```
зберегли файл → перебудувався index.html → коміт → push → GitHub Pages
```

Разово, без фонової служби:

```
python3 tools/autopublish.py --once
```

Журнал: `~/Library/Logs/school-autopublish.log`

## Як додати новий урок

Просто створити файл за структурою — решта станеться сама:

```
<Клас>/<Предмет>/Уроки/Урок N/Урок N — презентація для класу.html
```

Наприклад: `9-А/Інформатика/Уроки/Урок 2/Урок 2 — презентація для класу.html`

Тема на картці береться з тега `<title>` презентації, кількість слайдів
рахується автоматично. Нічого ніде не дублювати.

## Уроки, які проводили очно

Якщо в папці уроку є **тільки** вчительська хронокарта
(`Урок N — презентація.html`) і немає версії для класу — урок усе одно
з'явиться в списку, але з позначкою **ОЧНО** і **без посилання**.
Учень бачить, що урок був, і нумерація не збивається, але відкрити нічого
не може. Сам учительський файл на GitHub не потрапляє.

З'явиться для цього уроку `— презентація для класу.html` — картка
автоматично стане звичайним посиланням.

## Що бачать учні

На сайт потрапляють **тільки** файли `… — презентація для класу.html`.

GitHub Pages віддає будь-який файл репозиторію за прямим посиланням, тому
«немає посилання з index.html» саме по собі нічого не приховує. Захист дає
`.gitignore`: він побудований як **білий список** — спершу ігнорується все,
потім поіменно повертається дозволене.

Локально лишаються: вчительські хронокарти, підручники (PDF), КТП, `_Шаблони/`,
`Оцінювання/`.

> **Увага.** Новий тип файлу (картинка до уроку, шрифт) за замовчуванням
> **не** потрапить у репозиторій. Для нього треба дописати рядок-виняток
> у `.gitignore` — шаблон із поясненням є в кінці файлу.

## Чому index.html будується локально, а не на GitHub

Позначку **ОЧНО** можна поставити, лише побачивши вчительський файл. На GitHub
його немає (і не повинно бути), тому складання списку там дало б неповний
результат і мовчки видалило б очні уроки. Тому `index.html` завжди будує
`autopublish.py` на вашому комп'ютері — перед кожним комітом.

## Як увімкнути GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → гілка `main`, папка `/ (root)`.

Сайт буде за адресою `https://<нік>.github.io/<репозиторій>/`
