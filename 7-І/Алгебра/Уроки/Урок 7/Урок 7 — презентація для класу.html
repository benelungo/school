№ 93 і № 96 — звіряємо

№ 93 · доведіть

1) 3(2 − c) = 6 − 3c

Розкрили дужки: 6 − 3c = 6 − 3c — однакові вирази, тож підходить будь-яке число. ∎

2) x = x + 8

Права частина завжди на 8 більша за ліву — рівними не стануть. Коренів немає. ∎

№ 96 · рівносильні? яка властивість

1) 8(x − 1) = 5 і 8x − 8 = 5

так — властивість 1, розкрили дужки

2) 3x + 7 = 4x − 8 і 3x − 4x = −8 − 7

так — властивість 2, перенесли 4x і 7

3) 9(x + 2) = 18 і x + 2 = 2

так — властивість 3, поділили на 9

4) −3x4 = 7 і −3x = 28

так — властивість 3, помножили на 4

У чат — лише число

№ 102 (ст. 19) · усно · «підготуйтеся до нового матеріалу»

Розвʼяжіть рівняння

1) −3x = −21

x = −21 : (−3) = 7

2) −2x = 40

x = 40 : (−2) = −20

3) 0,2x = −5

x = −5 : 0,2 = −25

4) 50x = −5

x = −5 : 50 = −0,1

Усі чотири рівняння — одного вигляду: число · x = число. І розвʼязуються однаково: праву частину ділимо на число біля x.

У зошит — означення

Означення · ст. 19

Лінійне рівняння — це рівняння вигляду ax = b

Рівняння вигляду ax = b, де x — змінна, a і b — числа, називають лінійним рівнянням з однією змінною.

Числа a і b називають коефіцієнтами цього рівняння.

Ліворуч

число × змінна — і більше нічого: без «+ 5», без x2

Праворуч

тільки число — жодної змінної

Змінна

одна, у першому степені; буква може бути будь-яка: x, y, m…

У чат — номери лінійнихВголос — чому ні

№ 104 (ст. 22) · усно

Яке з рівнянь є лінійним?

1) 15x = 0

так: a = 15, b = 0

2) −7x = −12

так: a = −7, b = −12

3) x2 = 2x

ні — є x2, і змінна праворуч

4) 0x = 19

так: a = 0, b = 19

5) x + 3 = x2

ні — є x2

6) 0x = 0

так: a = 0, b = 0

Лінійних — чотири: 1, 2, 4, 6. Нуль у коефіцієнті не заважає рівнянню бути лінійним.

У чат: «Л», «З» або «Н»

Розпізнаємо · Л — лінійне, З — зводиться до лінійного, Н — ні

Уже лінійне чи треба перетворити?

1) 3x = 12

Л — вже вигляду ax = b

2) 3x − 5 = 7

З — перенесли −5: 3x = 12

3) x2 = 9

Н — змінна в квадраті

4) 2x = 5x + 6

З — перенесли 5x: −3x = 6

5) 6 : x = 2

Н — змінна в дільнику

6) x = −4

Л — a = 1, b = −4

Рівняння «З» ще не лінійні, але властивості з уроку 6 перетворюють їх на ax = b. Так розвʼязують більшість рівнянь 7 класу.

У зошит — схема

Схема · ст. 20

Скільки коренів має ax = b

якщо a ≠ 0

то x = ba

— один корінь

якщо a = b = 0

0x = 0

x — будь-яке число

якщо a = 0, b ≠ 0

0x = b

коренів не має

Чому? Нуль, помножений на будь-яке число, дає 0. Тож 0x = 0 правильне завжди, а 0x = 7 — ніколи.

У чат — 1…5

Що забираємо з уроку

Підсумок

Лінійне рівняння

Вигляду ax = b: ліворуч число × змінна, праворуч — число.

Коефіцієнти

Числа a і b, разом зі знаком. У «−x» a = −1, у «x» a = 1.

Корені

a ≠ 0 — один, x = ba;  0x = 0 — безліч;  0x = b, b ≠ 0 — немає.

Зводиться

Дужки → перенесення → подібні → ax = b.

У чат одне число: наскільки зрозуміло сьогодні — від 1 до 5.

На наступний урок

Домашнє завдання

§ 2, ст. 19–22;  № 109, № 112 (ст. 23)

№ 109 — як № 107 і № 108

Лінійні рівняння ax = b: ділимо b на a. Стеж за знаками й дробами.

№ 112 — як № 111 і приклад 3

Спершу звести до ax = b за планом, потім розвʼязати. Перевір підстановкою хоча б два пункти.

Дякую за урок

Наступного разу — той самий § 2: розвʼязуємо складніші рівняння, що зводяться до лінійних, і зʼясовуємо, коли вони рівносильні та скільки мають коренів.
